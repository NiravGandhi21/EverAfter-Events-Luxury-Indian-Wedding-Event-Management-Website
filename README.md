# EverAfter Events – Luxury Indian Wedding & Event Management Website

A **premium, full‑stack web application** that showcases a high‑end Indian wedding and event planning studio. The project started as a beautifully designed React + Vite front‑end generated by Bolt AI and has been **fully integrated into a native Flask + Jinja2 backend** to meet the B.Tech Semester‑5 PBL assignment requirements.

---

## ✨ Highlights & Design Language
- **Color palette** – ivory (`#f3f0ea`), charcoal (`#272725`), champagne (`#d8c8b5`), terracotta accents (`#9a7966`).
- **Typography** – *Playfair Display* for headings, *DM Sans* for body text.
- **Editorial layout** – spacious sections, rounded‑pill buttons, subtle hover effects, masonry‑style gallery.
- **Real photography** – all placeholder CSS gradients have been replaced with curated Unsplash/Pexels wedding photos stored locally under `static/images/`.
- **Responsive** – mobile‑first Tailwind CSS ensures the site looks great on phones, tablets and desktops.

## 🛠️ Tech Stack
| Layer | Technology |
|-------|------------|
| **Frontend** | React + TypeScript + Vite (reference design only) |
| **Backend** | Python 3.12, Flask, Jinja2 |
| **Database** | SQLite (via `instance/everafter.db`) |
| **Styling** | Tailwind CSS (compiled to `static/css/` ) |
| **Payments** | Razorpay test mode – order creation & HMAC‑SHA256 verification |
| **Email** | SMTP (Gmail app‑password) with audit‑log fallback |
| **Deployment** | Vercel (Python build) & Render (web‑service) |
| **Testing** | `pytest` – `test_everafter.py` covers all 5 PBL tasks |

---

## 📋 Core Features (fulfills the 5 mandatory PBL tasks)
1. **Full website integration** – every page (`/`, `/about`, `/services`, `/gallery`, `/contact`, `/blog`, `/login`, `/register`, `/payment` …) is served by Flask with Jinja2 template inheritance.
2. **Separate login & registration** – server‑side validation, password hashing with Werkzeug, SQLite persistence, flash‑message feedback.
3. **Show registration data on Home** – after a successful sign‑up the user’s name appears in a banner on the home page.
4. **Email notification on login** – successful and failed logins trigger an SMTP email; if SMTP fails the email body is stored in an `email_logs` table for audit.
5. **Razorpay payment demo** – create order, verify signature, record success/failure in SQLite, and display appropriate success/failure pages.

## 🚀 Getting Started (local development)
```powershell
# 1️⃣ Clone the repo (or unzip the existing folder)
cd path\to\your\workspace

# 2️⃣ Create a virtual environment and activate it
python -m venv .venv
.\.venv\Scripts\Activate.ps1   # PowerShell (or activate.bat for CMD)

# 3️⃣ Install Python dependencies
pip install -r requirements.txt

# 4️⃣ Create a .env file (copy from .env.example) and fill the secrets
copy .env.example .env
#   – SECRET_KEY, RAZORPAY_KEY_ID/SECRET, SMTP_HOST/PORT/USER/PASS

# 5️⃣ Initialise the SQLite DB (first run will also do this automatically)
python -c "import database; database.init_db()"

# 6️⃣ Run the Flask dev server
flask run   # or: python app.py

# Open http://127.0.0.1:5000 in your browser.
```

## 📦 Deploying to Vercel & Render
### Vercel
1. Push the repo to GitHub (see *Git & GitHub* section below).<br>
2. In the Vercel dashboard, **Import Project** → select your GitHub repo.
3. Vercel automatically detects a Python project. Set the **Build Command** to:
   ```
   pip install -r requirements.txt
   ```
   and the **Output Directory** to `static` (Vercel will serve the Flask app via `gunicorn`).
4. Add the required environment variables (`SECRET_KEY`, `RAZORPAY_*`, `SMTP_*`).
5. Deploy – Vercel will expose the app at `https://<your‑project>.vercel.app`.

### Render
1. In the Render dashboard choose **New → Web Service** and connect the same GitHub repo.
2. Set **Build Command** to `pip install -r requirements.txt` and **Start Command** to `gunicorn app:app`.
3. Define the same environment variables under **Environment → Add Environment Variable**.
4. Click **Create Web Service** – Render will build and publish the site at `https://<your‑project>.onrender.com`.
