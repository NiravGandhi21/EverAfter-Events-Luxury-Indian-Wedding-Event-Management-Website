This portal demonstrates end-to-end payment gateway workflows. Orders are created on the Flask server (`POST /payment/create-order`), executed via the Razorpay test modal, and verified on the backend (`POST /payment/verify`) using cryptographic HMAC-SHA256 hashing. Nominal test fees (₹500, ₹1,500, ₹3,000) are mapped to full wedding tier quotes for live sandbox evaluation.
